# BFS & 다익스트라
BFS는 연결 요소를 모두 방문
재귀 함수를 쓰지 않는다.

O(E+V) 노드개수 간선개수
시간 복잡도 최적화는 어렵다.
다른 부분에서 최적화 필요.


dfs 로 할 수 있는 것은 BFS로도 가능
연결요소의 개수와 크기 구하는것.

어떻게 구현하나
큐에 현재 값 넣고, 빼면서 연결된것들 넣는다. 반복
