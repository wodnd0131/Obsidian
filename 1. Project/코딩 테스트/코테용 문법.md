|`Collections.reverse(list)`|List 뒤집기|

# 배열/List/Set 간 변환 문법

## 배열 → 다른 자료구조

|변환|코드|
|---|---|
|배열 → List|`Arrays.asList(arr)` (수정 불가, add/remove 불가)|
|배열 → 수정 가능한 List|`new ArrayList<>(Arrays.asList(arr))`|
|배열 → Set|`new HashSet<>(Arrays.asList(arr))`|
|배열 → Stream|`Arrays.stream(arr)`|

## List → 다른 자료구조

|변환|코드|
|---|---|
|List → 배열 (Object[])|`list.toArray()`|
|List → 배열 (타입 지정, String[])|`list.toArray(new String[0])`|
|List → Set|`new HashSet<>(list)`|

## Set → 다른 자료구조

|변환|코드|
|---|---|
|Set → List|`new ArrayList<>(set)`|
|Set → 배열|`set.toArray(new String[0])`|

## 자주 걸리는 함정

|상황|문제점|해결|
|---|---|---|
|`Arrays.asList(arr)`에 `.add()`|`UnsupportedOperationException`|`new ArrayList<>(Arrays.asList(arr))`로 감싸기|
|`int[]`를 `Arrays.asList()`에 넣음|`List<int[]>`가 됨 (원소 1개짜리 List)|`int[]`는 `Integer[]`로 박싱 후 변환하거나, Stream 써야 함|
|`int[]` → `List<Integer>`|직접 변환 불가|`Arrays.stream(arr).boxed().collect(Collectors.toList())`|
|`List<Integer>` → `int[]`|직접 변환 불가|`list.stream().mapToInt(Integer::intValue).toArray()`|

특히 **`int[]`는 제네릭(`List<T>`, `Set<T>`)에 못 들어가요.** 원시타입이라서요. 
그래서 `int[]` ↔ `List<Integer>` 변환할 땐 항상 `boxed()`나 `mapToInt()`를 거쳐야 하는데, 
이 부분이 실전에서 제일 자주 막히는 지점이에요.
