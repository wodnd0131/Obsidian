## 알 수 있는 것
처음 원한 것 = 구간 get

누적합 배열을 사용하니까 점 get을 두번 쓰면된다.

누적합의 효능
- 구간 get 쿼리르 점 get 쿼리로 바꿔준다.
- 누적합을 쓰면 점 updqte가 구간 update가 된다.

prefix[n] - prefix[n-3]의 최댓값

![[../../../Repository/3주차-창고 다각형.png]]

접두사일 필요도 없어

2. 각 위치마다 min을 답에 더한다.
prefix_max[i] := 1~i 까지 최댓값
suffix_sum[i] := i~N 까지 중 최댓값

```
for i in range(1,n+1):
	prefix_max[i] = max(prefix_max[i-1],arr[i])
	
for(int i =n; i>=1; i--){
	suffix_max[i] = min(suffix_max[i-1],arr[i])
}
```
