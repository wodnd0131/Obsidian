# 백트래킹: 완전탐색에서 시작해 경우의 수 줄이기

## 0. 출발점: 재귀는 "n중 for문"을 만드는 도구다

3자리 5진수는 for문 3개를 중첩하면 된다. 그런데 자릿수 `n`이 입력으로 들어오면 for문을 몇 개 쓸지 코드를 짤 때 정할 수 없다. 재귀는 "반복문 하나 + 자기 자신 호출"로 중첩 깊이를 런타임에 정할 수 있게 해 준다.

- `cur` = 지금 몇 번째 for문(자리)에 있는지
- `cur == n` = 가장 안쪽 for문까지 다 돌았음 (기저 조건)

이후 모든 코드는 이 틀 하나에서 **"어떤 경우를 안 볼지"**만 바꿔 가는 과정이다. 표기는 강의 코드 기준으로 통일한다. **m개의 선택지(0 ~ m-1)에서 n개를 뽑는다.**

---

## 1. 중복 순열: O(mⁿ). 아무것도 거르지 않는 기준선

```python
n, m = map(int, input().split())
selected = []

def recur(cur):
    if cur == n:
        print(*selected)
        return
    for i in range(m):
        selected.append(i)
        recur(cur + 1)
        selected.pop()      # 돌아올 때 원상복구

recur(0)
```

**수학: 곱의 법칙.** 첫 자리에 m가지, 각각에 대해 둘째 자리에 m가지, … 가 n번 이어진다. 그래서 m × m × … × m = **mⁿ**이다. 3자리 5진수라면 5³ = 125개(000 ~ 444)가 나온다.

**append/pop을 하는 이유:** `selected`는 모든 재귀 호출이 공유하는 하나의 리스트다. 자식 호출에서 넣은 값을 빼지 않으면 형제 분기가 오염된다. **"들어갈 때 바꾼 상태는 나올 때 되돌린다"**는 원칙이 백트래킹 전체에 적용된다.

---

## 2. 순열: mⁿ → m!/(m−n)!. "이미 쓴 수"를 거른다

조건은 한 케이스 안에서 같은 수를 두 번 쓰지 않는 것이다.

```python
n, m = map(int, input().split())
selected = [0] * n
visited = [False] * m

def recur(cur):
    if cur == n:
        print(*selected)
        return
    for i in range(m):
        if visited[i]:          # 이미 뽑은 수 → 이 가지는 탐색 안 함
            continue
        visited[i] = True
        selected[cur] = i       # 덮어쓰기라 pop 불필요
        recur(cur + 1)
        visited[i] = False      # visited는 공유 상태 → 반드시 복구

recur(0)
```

**수학:** 선택지가 자리마다 하나씩 줄어든다.

- 첫 자리: m가지
- 둘째 자리: m−1가지
- n번째 자리: m−n+1가지

곱하면 m × (m−1) × … × (m−n+1)이다. 이걸 팩토리얼로 쓰면 다음과 같다.

$$  
{}_mP_n = \frac{m!}{(m-n)!}  
$$

분모가 곱셈의 뒷부분 (m−n)×…×1을 약분해서 없애는 것이라고 보면 된다. 예를 들어 5P3 = 5×4×3 = 120/2 = 60이다.

**무엇을 줄였나:** 중복 순열의 탐색 트리에서 "같은 수가 두 번 나오는 가지"를 통째로 잘라냈다. `visited` 배열 덕분에 "이미 썼는지" 확인이 O(1)이라 판별 비용도 거의 없다.

---

## 3. 조합: m!/(m−n)! → m!/(n!(m−n)!). "순서만 다른 것"을 거른다

`012`와 `210`은 같은 {0,1,2}다. 합, 곱처럼 순서가 결과에 영향이 없는 문제라면 순열은 같은 집합을 여러 번 보고 있는 셈이다.

**수학: 몇 번 중복되나?** {0,1,2}가 순열에서 나오는 모양은 012, 021, 102, 120, 201, 210으로 6개다. 서로 다른 n개를 한 줄로 세우는 방법의 수가 n!(3! = 6)이다. 즉 **모든 집합이 순열 안에서 정확히 n!번씩 중복**된다. 그러니 나눠 주면 된다.

$$  
{}_mC_n = \frac{{}_mP_n}{n!} = \frac{m!}{n!,(m-n)!}  
$$

**코드에서는 나누는 대신 대표 하나만 만든다.** 각 집합마다 "오름차순 배열"은 딱 하나뿐이다. 그래서 **항상 앞에서 고른 수보다 큰 수만 고르게** 강제하면 n!개 중 오름차순 하나만 생성된다.

```python
n, m = map(int, input().split())
selected = []

def recur(cur, start):
    if cur == n:
        print(*selected)
        return
    for i in range(start, m):   # 직전에 고른 수 다음부터만
        selected.append(i)
        recur(cur + 1, i + 1)
        selected.pop()

recur(0, 0)
```

이제 `visited`가 필요 없다. `start = i + 1`이 "뒤로만 간다"를 보장하니 같은 수를 다시 고를 수 없기 때문이다.

## 4. 부분집합 (고른다 / 안 고른다): O(2ⁿ)

"몇 개를 고를지 정해져 있지 않은" 문제에서 쓴다. 관점을 바꿔서, 원소마다 **"넣는다 / 안 넣는다"** 두 갈래로 분기한다. 이때 `cur`의 의미가 "몇 번째 자리"에서 **"몇 번째 원소를 결정 중인가"**로 바뀐다.

```python
n = int(input())
arr = [list(map(int, input().split())) for _ in range(n)]
answer = float('inf')

def recur(cur, cnt, s, b):
    global answer
    if cur == n:                      # 모든 재료에 대해 결정 완료
        if cnt > 0:                   # 공집합 제외
            answer = min(answer, abs(s - b))
        return
    recur(cur + 1, cnt + 1, s * arr[cur][0], b + arr[cur][1])  # 고름
    recur(cur + 1, cnt, s, b)                                  # 안 고름

recur(0, 0, 1, 0)   # 곱의 항등원 1, 합의 항등원 0
print(answer)
```

**수학:** 원소 n개가 각각 2가지 선택을 하니 2ⁿ이다. 크기별 조합을 전부 더한 것과 같다.

$$  
{}_nC_0 + {}_nC_1 + \cdots + {}_nC_n = 2^n  
$$

"크기로 나눠 세든, 원소별 O/X로 세든 같은 집합들을 세는 것"이라 값이 같다.

**참고:** 이 코드에서는 상태(`s`, `b`, `cnt`)를 **매개변수로 넘겨서** 복구 작업이 필요 없다. 호출이 끝나면 지역변수가 알아서 사라지기 때문이다. 공유 리스트 방식과 비교해 두면 좋다.

## 5. 진짜 백트래킹 = 가지치기

1~4는 사실 "문제 조건에 맞는 경우만 생성하는" 완탐이다. 백트래킹의 핵심은 여기에 **"이 가지는 더 가봐야 답이 안 된다"를 일찍 판단해 끊는 것**을 더하는 데 있다.

강의의 "2개만 뽑기" 코드를 가지치기 관점으로 고치면 다음과 같다. 원본은 `cur == n` 종료 조건이 없고, `recur(0, 0)` 호출 시 인자도 하나 빠져 있다.

```python
n = int(input())
ls = list(map(int, input().split()))
k = int(input())
count = 0

def recur(cur, total, cnt):
    global count
    if cnt == 2:                     # 가지치기 1: 목표 개수 달성 → 더 안 내려감
        if total == k:
            count += 1
        return
    if cur == n:                     # 원소 소진
        return
    if cnt + (n - cur) < 2:          # 가지치기 2: 남은 걸 다 골라도 2개 못 채움
        return
    recur(cur + 1, total + ls[cur], cnt + 1)
    recur(cur + 1, total, cnt)

recur(0, 0, 0)
print(count)
```

가지치기는 **최악의 시간복잡도(Big-O)를 바꾸지 않는 경우가 많다.** 대신 실제로 방문하는 노드 수를 크게 줄인다. 그래서 "경우의 수 계산으로 먼저 완탐 가능성을 판단하고, 부족하면 가지치기 조건을 찾는다"는 순서로 접근하면 된다.
